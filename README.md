# 📝 React Notes App

A simple and responsive Notes App built with **React**, **Vite**, and **Tailwind CSS**. This application allows users to create and delete notes with a clean, modern user interface.

## ✨ Features

- ➕ Add new notes
- 🗑️ Delete notes
- 📱 Responsive design
- 🎨 Modern UI with Tailwind CSS
- ⚡ Fast performance with Vite

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Lucide React Icons

## 📂 Project Structure

```
src/
├── assets/
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/react-notes-app.git
```

### Navigate to the project

```bash
cd react-notes-app
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
